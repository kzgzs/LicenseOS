隐私政策

最后更新日期：2026年7月11日

{site_name}（以下简称"本平台"）非常重视您的隐私保护。本隐私政策（以下简称"政策"）说明我们如何收集、使用、存储和保护您的个人信息。

1. 信息收集

我们可能收集以下类型的信息：

1.1 您主动提供的信息

  • 注册信息：邮箱地址、密码（以 bcrypt 加密存储）
  • 开发者信息：收款账户、税务信息、KYC 身份验证材料
  • 联系表单：您提交的咨询内容和联系方式
  • 支付信息：支付过程中提供的交易信息（由第三方支付平台处理，本平台不存储银行卡号或支付账户凭据）
  • 自由职业市场信息：个人技能、工作经历、项目提案、竞标信息
  • 工单信息：您提交的技术支持请求和沟通记录

1.2 自动收集的信息

  • 设备信息：浏览器类型、操作系统、IP 地址
  • 访问日志：访问时间、浏览页面、来源链接
  • Cookie 和类似技术：用于维持登录状态、推广追踪和改善用户体验
  • 广告交互数据：广告展示和点击记录

2. 信息使用

我们使用收集的信息用于以下目的：

  • 提供、维护和改进本平台服务（数字商品交易、许可证管理、自由职业市场等）
  • 处理交易和发送相关通知（订单确认、授权到期提醒、评价邀请）
  • 验证身份和防止欺诈（包括开发者 KYC 审核）
  • 发送服务相关的邮件和短信通知
  • 处理推广联盟佣金追踪和结算
  • 执行许可证激活、域名绑定和防篡改检测
  • 回应您的咨询和提供客户支持（含工单系统和技术专家推荐）
  • 分析平台使用情况以改善用户体验
  • 运营和优化平台内广告系统

3. 第三方服务

本平台使用以下第三方支付和服务提供商，各自按照其隐私政策处理您的数据：

3.1 支付服务

  • 微信支付：处理微信渠道的付款交易，收集您的微信账户标识和交易信息。数据由腾讯科技处理，详见微信支付隐私政策。
  • 支付宝：处理支付宝渠道的付款交易，收集您的支付宝账户标识和交易信息。数据由蚂蚁集团处理，详见支付宝隐私政策。
  • Stripe：处理国际信用卡及其他支付方式的交易，收集卡号、持卡人姓名等支付凭据。本平台不存储完整卡号，数据由 Stripe Inc. 处理，详见 stripe.com/privacy。

3.2 云存储服务

  • Cloudflare R2：用于存储产品文件（如插件安装包、更新包等）。数据可能存储在 Cloudflare 全球网络的多个区域，涉及跨境数据传输。

3.3 通信服务

  • 邮件服务：用于发送订单确认、评价邀请、邮箱验证、许可证到期提醒等通知邮件。
  • 短信服务：用于发送验证码和交易通知短信。

4. Cookie 使用

4.1 我们使用以下类型的 Cookie：

  • 会话 Cookie：维持您的登录状态和偏好设置，关闭浏览器后失效。
  • 推广追踪 Cookie（affiliate_ref）：当您通过推广链接访问本平台时，我们在您的浏览器中设置 affiliate_ref Cookie，用于记录推荐来源以便计算推广佣金。该 Cookie 具有有限的有效期。

4.2 您可以通过浏览器设置管理或禁用 Cookie，但禁用会话 Cookie 将影响登录等核心功能的使用。

4.3 本平台运营自有 CPC 广告系统，广告展示和点击追踪由平台内部处理，不使用第三方广告网络追踪 Cookie。

5. 自由职业市场数据

5.1 如您参与自由职业市场（人才市场或竞标市场），我们收集和处理以下数据：

  • 竞标信息：您提交的项目提案、报价和时间估算
  • 项目合同：双方约定的工作范围、里程碑和付款条件
  • 托管资金（Escrow）：项目款项的托管和释放记录
  • 争议证据：如发生争议，双方提交的沟通记录、交付物和其他相关证据
  • 评价信息：项目完成后双方互评的内容

5.2 自由职业市场数据在争议解决期间可能被保留和查阅，争议解决后按平台规则处理。

6. 防篡改检测数据

6.1 为保障许可证安全和软件完整性，本平台执行防篡改检测，收集以下数据：

  • 域名激活状态：记录许可证绑定的域名信息
  • 篡改标记：检测并记录产品文件是否被未授权修改
  • 域名完整性日志：定期检测的验证结果记录

6.2 这些数据仅用于许可证安全验证，不涉及用户个人行为的追踪。

7. 广告系统

7.1 本平台运营竞价 CPC（按点击付费）广告系统。

7.2 我们记录广告的展示次数和点击行为，用于计费、效果分析和防止虚假点击。

7.3 广告交互数据不用于站外追踪，不与第三方广告网络共享。

8. 信息存储与安全

8.1 您的个人信息存储在安全的服务器上，采用加密存储和传输。

8.2 密码以 bcrypt 加密形式存储，任何人（包括平台管理员）无法查看您的原始密码。

8.3 产品文件存储于 Cloudflare R2，数据可能涉及跨境传输。通过使用 Cloudflare 服务，您的数据可能被传输至您所在国家/地区以外的服务器。

8.4 我们保留您的信息直至账户删除或不再需要为止。

8.5 交易记录按照法律要求保留不少于 5 年。

9. 信息共享

我们不会出售您的个人信息。仅在以下情况下可能与第三方共享：

  • 支付处理：为完成交易与微信支付、支付宝、Stripe 共享必要信息
  • 法律要求：应法律法规要求或司法/行政机关命令
  • 服务提供者：与帮助我们运营平台的服务商共享（如邮件服务、短信服务、云存储）
  • 开发者：购买产品时，开发者可查看必要的授权信息（不含支付细节）
  • 争议仲裁：自由职业市场争议中，向争议双方和仲裁人员展示相关证据

10. 邮件与短信通知

10.1 我们会通过邮件发送以下通知：订单确认、评价邀请、邮箱验证、许可证到期提醒、平台公告等。

10.2 我们会通过短信发送验证码和重要交易通知。

10.3 您可以在账户设置中管理通知偏好，但交易关键通知（如订单确认、安全验证）无法关闭。

11. 您的权利

您享有以下权利：

  • 访问权：您可以查看我们持有的您的个人信息
  • 更正权：您可以要求更正不准确的个人信息
  • 删除权：在法律允许的范围内，您可以要求删除您的个人信息
  • 数据可携权：您可以要求导出您的个人数据

12. 安全措施

我们采取以下安全措施保护您的信息：

  • 数据传输加密（HTTPS/TLS）
  • 密码加密存储（bcrypt）
  • 定期安全审计和漏洞修复
  • 访问控制和权限管理
  • 邮箱验证机制
  • 许可证防篡改检测系统

13. 儿童隐私

本平台服务不面向 18 岁以下的未成年人。我们不会故意收集未成年人的个人信息。

14. 政策更新

14.1 我们可能会不时更新本隐私政策。

14.2 重大变更将通过平台公告或邮件通知。

14.3 更新后的政策在平台上发布后立即生效。

15. 联系方式

如对本隐私政策有任何疑问或需要行使您的权利，请通过本平台的联系页面与我们取得联系。
